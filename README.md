# Flutter Container Presentation

**What is it?**

It's a Flutter widget that combines multiple other widgets such as: `Padding`, `Align`, `ConstrainedBox`, `DecoratedBox`, or `Transform`.

We use it  when we need a widget that we can size, space, color, and shape.

**Main properties**

| Property | What it does |
|---|---|
| `width` / `height` | Fixed size of the box |
| `color` | Simple background color |
| `decoration` | Advanced styling: border, radius, gradient, shadow, image |
| `padding` | Space *inside* the box, between the edge and the child |
| `margin` | Space *outside* the box, between it and its neighbors |
| `alignment` | Where the child sits inside the box |
| `constraints` | Min/max width and height |
| `transform` | Rotate, scale, or translate the box |
| `foregroundDecoration` | Decoration painted *on top of* the child |
| `clipBehavior` | Clips the child to the decoration's shape |
